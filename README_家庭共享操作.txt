小公主存股星球 M2｜家庭唯讀共享補丁
=================================

目的：你和老婆用各自 Email 登入，查看同一份女兒帳本。老婆只能看，不能修改成交、設定或交易紀錄。
原始 Q 版角色、KD 買點、22 年試算、雲端共用設定均保留。

A｜先備份
1. 你目前的網站若已有正式交易，先在「設定與備份」下載完整 JSON。
2. 不要在 GitHub 上傳 JSON、私人 Email 清單、密碼或券商 API 金鑰。

B｜更新 Supabase
1. 登入 Supabase Dashboard → SQL Editor → New query。
2. 開啟 sql/002_family_readonly.sql，完整複製貼上，按 Run。
3. 這是增量升級：保留原本 portfolio_states，新增家庭授權資料表及權限函式。

C｜更新 GitHub Pages
1. 解壓縮本補丁，進入你的 erita2114/princess-stock 儲存庫。
2. 將新版 mobile-cloud.js 上傳到專案最外層，取代同名檔案，Commit changes。
3. 你已經設定好的 cloud-config.json 不需要更動。
4. 等 GitHub Pages 部署完成，在手機瀏覽器重新整理，必要時清理單一網站快取。

D｜邀請老婆
1. 你用原本 Email 登入網站，進入「設定與備份」。
2. 下方「家庭共享」填入老婆的 Email →「授權唯讀查看」。
3. 把既有 GitHub Pages 網址傳給老婆。
4. 老婆用自己的 Email 登入並點確認信連結。
5. 登入後顯示同一份帳本，且出現「家庭共享唯讀」。她不能編輯交易。
6. 不必共享你的登入信箱，也不用老婆建立第二個空白帳本。

E｜登入特性
每台裝置第一次要各自驗證 Email，之後 Supabase 會盡可能保存登入狀態；
使用無痕模式、清除網站資料、授權到期或登出時可能再次要求驗證。
此補丁沒有建立公開免登入模式，以免女兒私人財務資料外洩。

F｜撤銷與限制
你可以在「家庭共享」填同一 Email，按「撤銷這個 Email」。
取消權限後，已經開啟的頁面可能仍暫時顯示之前載入的畫面，但重新同步或新資料請求會被拒絕。
目前同一個帳本最多 3 位唯讀家人。不同人請用自己的 Email。
此補丁未包含永豐正式行情授權與背景寄信，仍然需要獨立雲端行情服務。
